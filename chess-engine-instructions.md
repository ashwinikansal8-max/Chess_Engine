# Project Instructions

- Work directly with existing project files.
- Prefer creating and editing files over printing code in chat.
- When given Markdown coding instructions, extract only code
  inside the relevant language-specific fenced code blocks.
- Ignore explanations, tutorials, descriptions, and text outside
  code blocks.
- Never copy explanatory paragraphs into source files.
- Follow existing package structures and naming conventions.
- Avoid duplicate classes and unnecessary rewrites.
- Build and verify changes after implementation.
- Preserve existing work and never commit or push without permission.
